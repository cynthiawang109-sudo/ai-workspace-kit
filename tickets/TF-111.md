# TF-111: Dependency and code-scanning automation, security policy

- Project: ai-workspace-kit (all six repos)
- Status: open
- Priority: medium

## Problem

Nothing watches the workspace's dependencies or code for known
vulnerabilities: no Dependabot configuration, no code scanning,
and no published security policy telling a finder where to report
a problem. For a portfolio that argues production habits, the
supply-chain side is currently all manual.

## Change

1. **demo-app (via PR, reviewed as usual):**
   - `.github/dependabot.yml`: weekly updates for `pip` (`/`) and
     `github-actions` (`/`).
   - `.github/workflows/codeql.yml`: CodeQL analysis for Python on
     pushes to `main`, pull requests, and a weekly schedule.
   - `SECURITY.md`: supported versions and private reporting via
     GitHub's vulnerability reporting for this repository.
2. **ai-workspace-kit (direct):** the same three pieces, with the
   `pip` entry pointed at `/mcp/doc-search` (the only Python
   package in the repo) and CodeQL scoped to Python.
3. **taskflow-docs, taskflow-api-docs (direct):** `dependabot.yml`
   for `github-actions` only (the only ecosystem present), and a
   brief `SECURITY.md`. No CodeQL: the only Python present is the
   stdlib docs checker, with no dependencies.
4. **code-reviewer, release-assistant (direct):** a brief
   `SECURITY.md` only — no dependency ecosystem and no
   CodeQL-supported language (PowerShell/Shell scripts).
5. **Private vulnerability reporting** is enabled on every repo
   that carries a `SECURITY.md`, so the documented reporting path
   actually exists.
6. When all sub-repo changes land, bump `versions.txt` per the
   TF-110 convention and commit.

## Acceptance

- The demo-app PR's CI is green including the new CodeQL job, and
  the PR goes through the standard review before merging.
- CodeQL completes on ai-workspace-kit's `main` after the direct
  commit.
- Every `SECURITY.md` renders on its repo and its reporting link
  resolves to a live advisories page.
- Doctor is green after the pins bump.
