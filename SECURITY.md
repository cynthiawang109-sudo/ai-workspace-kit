# Security policy

## Supported versions

Security fixes are applied to `main`; the sub-repositories carry
their own policies. There are no numbered releases of the
workspace itself.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.
Use this repository's **Security** tab and choose **Report a
vulnerability** (GitHub private vulnerability reporting). Reports
are reviewed within a few days.

## Scope

In scope: the doc-search MCP server, the sync and doctor
scripts, the workspace skills, and the CI workflows. The
workspace contains only fictional TaskFlow material; never
submit real credentials or employer data in a report.
