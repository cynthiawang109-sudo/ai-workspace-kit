## Problem

The worker's digest job retries on failure without logging the attempt
count, and a retry after a partial send can deliver the digest twice. Per
`taskflow-docs/system-overview.md` the retry ceiling is 5 attempts before
dead-letter; the job should log each attempt with the user ID (never the
email address — PII rule) and make sends idempotent per week.
