## Problem

`taskflow-docs/observability.md` specifies what every service
emits: structured JSON logs with required fields (`ts`, `service`,
`level`, `request_id`), a request ID minted at the edge and
propagated so one user action can be followed across services, and
the standing rule that logs carry IDs only — PII in logs is a
severity-1 incident. demo-app emits none of this: it is the one
documented cross-cutting behavior with no running code behind it,
and its silence in the logs makes the demo's own failure modes
(down store, validation errors) invisible except through responses.

## Scope (demo slice, in demo-app)

- A middleware (pure ASGI preferred — no response buffering) that,
  for every request including `/health`:
  - Honors an inbound `X-Request-ID` header, otherwise mints a
    request ID; echoes it as the `X-Request-ID` response header.
  - Emits exactly one structured JSON line to stdout per request:
    `ts` (ISO-8601 UTC), `service` (`demo-app`), `level` (`info`,
    or `error` when the response is 5xx), `request_id`, `method`,
    `path` (no query string), `status`, `duration_ms`.
  - Never logs request or response bodies, headers beyond the
    request ID, or query values — log lines carry no user content,
    per the severity-1 rule.
  - `user_id` is omitted: the field is required only when a user
    context exists, and the demo has no authentication.
- Metrics, traces, central log shipping, and propagation into
  worker job payloads stay production-only, and are out of scope.
- Tests: the line parses as JSON with the required fields and
  types; the logged `request_id` equals the response header; two
  requests get distinct IDs; an inbound `X-Request-ID` is
  propagated; a 404 and a 503 both produce log lines with their
  status (5xx at `error` level); and a PII tripwire — a task title
  and a comment body created through the API never appear in any
  captured log line.
- Docs are updated after this merges (an observability demo note),
  so the documentation never claims the behavior early.
