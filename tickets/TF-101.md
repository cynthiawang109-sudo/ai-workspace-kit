## Problem

`demo-app`'s `/health` always returns `200 {"status": "ok"}`. The contract in
`taskflow-api-docs/api-conventions.md` ("Health checks") requires a `503`
with `{"status": "degraded", "checks": {"db": "down"}}` when a hard
dependency is unreachable.

Currently accepted as a known gap (see `code-reviewer/projects/demo-app.md`:
no hard dependencies exist yet). This ticket becomes actionable the moment
demo-app gains a real database or queue dependency: the dependency check and
the 503 branch land in the same change.
